# Kurs

Schulplaner fürs Abitur als iPad-App: Jetzt-Ansicht mit laufender Stunde, Hausaufgaben mit automatischem
Datum aus dem Stundenplan, Wochenansicht, Klausuren mit Lernplan, Fokus-Timer, Notizen, Noten und
Abi-Rechner (NRW-Modell einstellbar).

**Installieren:** Seite in Safari öffnen → Teilen-Symbol → „Zum Home-Bildschirm“.
Die App läuft danach im Vollbild und offline.

**Daten:** liegen nur auf dem Gerät (localStorage), nicht in diesem Repository.
Sichern und übertragen über Einstellungen → „Daten kopieren“ / „Daten einfügen“.

Diese Dateien werden gebaut – Quelle ist `schule/kurs.html` mit `schule/build_app.py`.
