# Punktekonto

Schulplaner fürs Abitur als iPad-App: Hausaufgaben mit automatischem Datum aus dem Stundenplan,
Wochenansicht, Klausuren mit Lernplan, Notizen, Noten und Abi-Rechner (NRW-Modell einstellbar).

**Installieren:** Seite in Safari öffnen → Teilen-Symbol → „Zum Home-Bildschirm“.
Die App läuft danach im Vollbild und offline.

**Daten:** liegen nur auf dem Gerät (localStorage), nicht in diesem Repository.
Sichern und übertragen über Einstellungen → „Daten kopieren“ / „Daten einfügen“.

Diese Dateien werden gebaut – Quelle ist `schule/punktekonto.html` mit `schule/build_app.py`.
